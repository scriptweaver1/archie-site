ArchangelsBabe masterlist: front-end preview (no database, no admin)

View it on your computer:  open this folder in a terminal and run   py -m http.server   then go to http://localhost:8000
Put it online for the client: drag this whole folder into Cloudflare Pages (Direct Upload), or push it to GitHub and connect the repo (no build command, output directory = this folder).

Edit data:  data/audios.json (audios), data/art.json (art), js/config.js (nav links, categories, Discord page text).
